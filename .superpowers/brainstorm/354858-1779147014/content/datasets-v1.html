MontanaBlotter: Public Datasets (v1)

Pick what to launch first. Click cards to select (multi-select).

Proposed IA
  • /datasets — directory of datasets (MT-only), with “Last updated” and coverage (counties/cities)
  • /datasets/<slug> — per-dataset landing page (charts + browse + methodology)
  • /datasets/<slug>/records — filterable explorer (existing records table views + dataset-specific filters)
A

Jail Bookings

Daily bookings by county. Explorer + trends by day/week.

Priority: Great Falls (Cascade), Billings (Yellowstone), Missoula

B

Police Calls / Calls-for-Service

Daily call logs where available. Explorer + hotspot/time-of-day summaries.

Priority: Great Falls, Billings, Missoula

C

Crime Map Events (Official dashboards)

City-linked dashboards (when official). Explorer + incident type mix.

Best where agencies publish structured feeds.

D

Court Filings / Dockets

Daily update of new cases/entries. Explorer + “case journey” links.

Higher complexity, high value.

E

Code Violations / Property Intelligence

Existing code-violations surfaces → elevate into a dataset page.

Pairs well with eviction + civil filings pages.

F

Professional License Sanctions

State boards. Explorer + “discipline type” breakdown.

Usually clean structured sources.

G

Sex Offender Registry (State)

Statewide updates. Explorer + change log over time.

Careful UX + disclaimers.

H

Missing Persons (State/Local)

Listings + updates. Explorer + status changes.

Strong community value.

I

Public Meetings / Agendas

City/county boards. Calendar view + agenda archive.

Great Falls, Billings, Missoula first.

Daily Cron “Automizer” (system cron)
  1. Fetch/update datasets (ingestion scripts)
  2. Recompute aggregates for dataset pages (counts, trends)
  3. Invalidate caches + update “Last updated” timestamps
  4. (Optional later) auto-post daily roundup to the site/social
