Command Center

Command Center Runbook

Current production checks for the admin operations console, Flask app, nginx edge, Redis, and background pipelines.

Primary Flask App

Gunicorn serves the Flask app on 127.0.0.1:5000 behind nginx.

Redis

Redis is local-only on 127.0.0.1:6379 for queues, cache, and live ops state.

Agent Events Sidecar

The legacy FastAPI sidecar is currently disabled. Do not enable it unless a live agent-events workflow explicitly requires port 8010.

Health Checks

Confirm the public route and local service state

# Public admin route should redirect unauthenticated users to login
curl -sSI https://montanablotter.com/admin/operations/runbook

# Flask app should be active
systemctl status montanablotter.service --no-pager

# Gunicorn should be bound locally
ss -ltnp | rg '127.0.0.1:5000|:443|:80'

# Redis should be listening locally
ss -ltnp | rg '127.0.0.1:6379'

Operations

Restart and log commands

Restart Flask after code or template deploys

systemctl restart montanablotter.service
systemctl status montanablotter.service --no-pager

Inspect recent app logs

tail -n 120 /root/montanablotter/logs/gunicorn.log
journalctl -u montanablotter.service --since '30 minutes ago' --no-pager

Pipelines

Check ingestion and scheduled work

# Cron schedule
crontab -l

# Recent scheduled job output
tail -n 120 /root/montanablotter/logs/cron.log
tail -n 120 /root/montanablotter/logs/cron_errors.log

# Source-specific diagnostics
tail -n 80 /root/montanablotter/logs/agendas_ingest.log
tail -n 80 /root/montanablotter/logs/jail_booking_ingest.log
tail -n 80 /root/montanablotter/logs/ingestion_alerts.log

Legacy Sidecar

montanablotter-agent-events.service is intentionally treated as optional. If a future workflow needs it, verify the unit points at services.agents.events_service:app, then start it explicitly and confirm port 8010 before updating this runbook.
