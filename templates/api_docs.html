Montana Blotter Public API

Pull public post and records data directly. Use the ids filter to reference specific posts by ID.

{% endblock %} {% block content %}

Base URL

All endpoints are public JSON endpoints.

{{ base_url }}/api

Reference Specific Posts

Use ids with comma-separated numeric IDs.

GET {{ base_url }}/api/posts?ids=123,456,789

Each post includes a post_url field for direct linking.

Core Endpoints

Posts List

GET {{ base_url }}/api/posts?page=1&per_page=20&county=Gallatin&search=theft

Single Post

GET {{ base_url }}/api/posts/123

Records

GET {{ base_url }}/api/records?page=1&per_page=20&county=Yellowstone

Agencies

GET {{ base_url }}/api/agencies

Counties

GET {{ base_url }}/api/counties

Example Response

{
  "posts": [
    {
      "id": 123,
      "title": "Daily Blotter Report",
      "county": "Gallatin",
      "incident_date": "03/05/26",
      "post_url": "{{ base_url }}/post/123"
    }
  ],
  "total": 1,
  "page": 1,
  "per_page": 20,
  "total_pages": 1
}

Usage Notes

  • All responses are JSON.
  • Read-only endpoints are CORS-enabled for GET/HEAD/OPTIONS.
  • Use reasonable polling intervals for production integrations.
