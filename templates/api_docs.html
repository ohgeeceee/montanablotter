Public REST API

Montana Blotter API

Free, open access to Montana law enforcement incident data. No API key required. All responses are JSON. Base URL: https://montanablotter.com

No Auth Required Updated in Real-time REST / JSON 56 Montana Counties OpenAPI Spec

Endpoints

GET /api/stats GET /api/posts GET /api/posts/:id GET /api/records GET /api/records/:id GET /api/blotters GET /api/blotters/:id GET /api/counties GET /api/agencies GET /api/blog
GET /api/stats

Overall database statistics — total record counts, agencies, counties, and latest blotter date.

{
  "total_records": 4821,
  "total_posts": 142,
  "total_blotters": 68,
  "total_counties": 12,
  "total_agencies": 18,
  "latest_blotter": {
    "county": "Lewis and Clark",
    "upload_date": "2026-02-21 16:00:01"
  }
}
GET /api/posts

AI-generated daily digest posts, paginated. Each post summarises one agency's blotter for a given date.

ParameterTypeDescription
countystringFilter by county name (e.g. Gallatin)
agency_typestringsheriff, police, or other
date_fromstringStart date filter YYYY-MM-DD
date_tostringEnd date filter YYYY-MM-DD
searchstringFull-text search across title and summary
pageintegerPage number (default: 1)
per_pageintegerResults per page (default: 20, max: 100)
 
{
  "posts": [
    {
      "id": 14,
      "title": "Daily Activity Report – Helena Police Department",
      "summary": "The Helena PD responded to 6 incidents...",
      "county": "Lewis and Clark",
      "agency_name": "Helena Police Department",
      "agency_type": "police",
      "incident_date": "02/20/26",
      "incident_type": "Daily Digest",
      "created_at": "2026-02-21 16:00:02"
    }
  ],
  "total": 142,
  "page": 1,
  "per_page": 20,
  "total_pages": 8
}
GET /api/posts/:id

Returns a single post by ID. Returns 404 if not found.

GET /api/posts/14

{

  "title": "Daily Activity Report – Helena Police Department",

  "agency_type": "police",
  "incident_date": "02/20/26",
  "incident_type": "Daily Digest",
  "created_at": "2026-02-21 16:00:02"
}
GET /api/records

Raw individual incident records parsed from blotter PDFs, paginated.

ParameterTypeDescription
countystringFilter by county name
incident_typestringPartial match on incident type (e.g. Theft)
date_fromstringStart incident date YYYY-MM-DD
date_tostringEnd incident date YYYY-MM-DD
searchstringSearch incident type, details, and location
pageintegerPage number (default: 1)
per_pageintegerResults per page (default: 20, max: 100)
 
{
  "records": [
    {
      "id": 301,
      "blotter_id": 16,
      "cfs_number": "26-001234",
      "date": "2026-02-20",
      "time": "11:29",
      "incident_type": "Warrant Arrest",
      "location": "100 block of N Rodney St",
      "details": "Subject arrested on outstanding warrant.",
      "county": "Lewis and Clark",
      "officer": "Officer Smith",
      "created_at": "2026-02-21 16:00:01"
    }
  ],
  "total": 4821,
  "page": 1,
  "per_page": 20,
  "total_pages": 242
}

  "location": "100 block of N Rodney St",

GET /api/blotters

List of processed blotter batches (each PDF or email submission is one blotter).

ParameterTypeDescription
countystringFilter by county name
pageintegerPage number (default: 1)
per_pageintegerResults per page (default: 20, max: 100)
 
{
  "blotters": [
    {
      "id": 16,
      "filename": "helena_pd_20260220.pdf",
      "county": "Lewis and Clark",
      "upload_date": "2026-02-21 16:00:01",
      "incident_count": 6,
      "source_type": "pdf"
    }
  ],
  "total": 68,
  "page": 1,
  "per_page": 20,
  "total_pages": 4
}

GET /api/counties

All counties in the database with post and record counts, sorted by activity.

{
  "counties": [
    {
      "county": "Lewis and Clark",
      "post_count": 42,
      "record_count": 310
    }
  ]
}
GET /api/agencies

All agencies that have submitted blotters, with post counts and type classification.

{
  "agencies": [
    {
      "agency_name": "Gallatin County Sheriff",
      "agency_type": "sheriff",
      "county": "Gallatin",
      "post_count": 42
    }
  ]
}
GET /api/blog

Published blog posts, paginated. For a single post, use /api/blog/:slug.

ParameterTypeDescription
pageintegerPage number (default: 1)
per_pageintegerResults per page (default: 10, max: 50)
 
{
  "posts": [
    {
      "id": 1,
      "title": "Understanding Montana's Public Records Laws",
      "slug": "understanding-montana-public-records",
      "excerpt": "A guide to accessing law enforcement records...",
      "author": "Montana Blotter",
      "created_at": "2026-02-15 10:00:00"
    }
  ],
  "total": 5,
  "page": 1,
  "total_pages": 1
}

Usage

This API is free and open with no rate limits for reasonable use. All data is public law enforcement information. If you're building something with this data, we'd love to hear about it — reach out at records@montanablotter.com.
