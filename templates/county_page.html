How to Find Arrest Records in {{ county.name }} County

Arrest records in {{ county.name }} County are public documents under Montana's public records laws. There are several ways to access them:

  1. 1 Montana Blotter (this site) — Free, AI-summarized daily activity reports from law enforcement agencies serving {{ county.name }} County. No account required.
  2. 2 {{ county.name }} County Jail Roster — The {% if county.roster_url %} {{ county.name }} County Detention Center {% else %} {{ county.name }} County Detention Center (available by phone at {{ county.phone }}) {% endif %} posts a live roster of current inmates.
  3. 3 Montana DOJ Criminal History — The Criminal History Online Public Records Search (CHOPRS) allows name-based searches of felony and misdemeanor charges statewide for a $20 fee.
  4. 4 Montana Courts Portal — Montana's public court access portal provides case-level criminal records for district courts and limited jurisdiction courts statewide.

How to Check Active Warrants in {{ county.name }} County

Active arrest warrants and bench warrants in {{ county.name }} County are public records. You can search for them through the Montana Judicial Branch Public Access Portal — select "Warrants" under the defendant search drop-down. {% if county.warrant_url %} The {{ county.name }} County warrant list is also available directly from the county. {% endif %} You can also call the {{ county.name }} County Sheriff's Office at {{ county.phone }} to inquire about active warrants.
