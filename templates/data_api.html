Endpoints

GET /api/v1/data/records

Paginated police blotter records.

curl -H "Authorization: Bearer $TOKEN" \
  "https://montanablotter.com/api/v1/data/records?county=Gallatin&since=2026-01-01&limit=100&page=1"

Query params: county, since (YYYY-MM-DD), until, limit (max 500), page.

GET /api/v1/data/warrants

Active and historical warrants. By default returns active; pass status=cleared for resolved records.

curl -H "Authorization: Bearer $TOKEN" \
  "https://montanablotter.com/api/v1/data/warrants?county=Yellowstone&limit=50"

GET /api/v1/data/jail-bookings

Jail bookings with charges and bond amounts. since accepts YYYY-MM-DD.

curl -H "Authorization: Bearer $TOKEN" \
  "https://montanablotter.com/api/v1/data/jail-bookings?since=2026-05-01&limit=200"

GET /api/v1/data/posts

Published editorial posts (summaries, digests, blotter articles). Includes SEO metadata.

curl -H "Authorization: Bearer $TOKEN" \
  "https://montanablotter.com/api/v1/data/posts?county=Missoula&page=1"

GET /api/v1/data/summary

Aggregate counts: total records, active vs. cleared warrants, bookings in the last 30 days, published posts, and a per-county record breakdown.

curl -H "Authorization: Bearer $TOKEN" \
  "https://montanablotter.com/api/v1/data/summary"

Tiers & rate limits

Tier Rate limit Typical use
standard 60 req/min Researchers, single-developer use, journalists running ad-hoc analyses.
pro 300 req/min Newsroom dashboards, civic-tech integrations, periodic bulk syncs.
enterprise Custom Continuous data pipelines, multi-org sharing, custom S3/GCS drops.

Get a token

Tokens are issued by admin. Email data@montanablotter.com with:

  • Your name and organization (academic, newsroom, civic-tech, commercial).
  • A one-sentence description of what you'll use the data for.
  • Preferred tier and whether you need a non-expiring token.

Free standard tokens are issued to journalists, academic researchers, and government offices. Commercial use and resold data feeds require a paid pro or enterprise plan.

Response shape

Same envelope across endpoints.

{
  "tier": "standard",
  "page": 1,
  "per_page": 100,
  "total": 13878,
  "count": 100,
  "records": [...]
}

Errors

  • 401 missing or invalid bearer token.
  • 429 rate limit exceeded — wait a minute and retry.
  • 500 upstream SQLite issue — retry with backoff.

CORS

All v1 endpoints return Access-Control-Allow-Origin: *. You can call them from browser code if your token is safe to expose — for browser apps, prefer a server-side proxy.
