Endpoint

GET / POST /api/v1/disposition/lookup

Match a person or case number to Montana court outcomes. Returns every criminal case (filed & closed), the disposition & sentence, plus any related jail bookings. 

curl -H "Authorization: Bearer $TOKEN" \
  "https://montanablotter.com/api/v1/disposition/lookup?name=Wood,+Danielle&county=Sanders&include_bookings=1"

Query params (GET) / JSON body (POST):

  • name — free-form person name: "Brian Laird", "Laird, Brian", "Laird, Brian Q". Required if case_number omitted.
  • case_number — exact case number (e.g. "DA 17-0348"). Required if name omitted.
  • county — optional filter: narrows both court cases and jail bookings. Use the full county name ("Yellowstone", "Missoula").
  • include_bookings — 1 (default) returns related jail bookings; 0 skips them for a faster response.
  • limit — max cases per person. Default 25, max 100.

Matching confidence

Each match carries a match_type and confidence so you can decide what to keep:

match_type confidence When it fires
case_number 1.0 Exact match on a supplied case_number.
exact_slug 1.0 Normalized name slug matches a stored court_cases.defendant_slug.
last_first 0.9 Last name exact + first name prefix matches.
last_only 0.7 Last name only (no first supplied). Multiple people may match — review carefully.

The watchlist: we follow every new arrestee

Lookup-on-demand is the read side. The watchlist is the write side — and it's where this product is genuinely different.

Every 15 minutes, our system pulls the newest Montana jail bookings and, for each one, runs the same disposition lookup against the court case database. When a person arrested today eventually has a case filed, plea entered, or sentence handed down, we record the link and the outcome snapshot.

On the next refresh, any change in disposition, sentence_text, sentence_date, or sentencing_judge is detected and a fresh find_pending_notifications is flagged. The admin dashboard at /admin/case-watch surfaces new outcomes for review.

Watchlist access is included with every Disposition API subscription. No separate add-on.

Data coverage

Court case outcomes are scraped from the Montana Supreme Court opinions API and a growing set of district-court sources. Jail bookings come from county sheriff rosters (currently 7 of 56 Montana counties, expanding).

  • Court cases: dispositions, pleas, sentences, sentencing judges, charge text, original trial court.
  • Jail bookings: person name, age, booking/release timestamps, charges summary, facility, current status.
  • Cross-link: every court case is matched to related jail bookings by last + first name (county-scoped), so a single API call returns the full story.

Coverage grows every week. The data_as_of timestamp on every response tells you when the data was last refreshed.
