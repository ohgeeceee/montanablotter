Embed No signup

The shortest possible integration.

The script auto-injects into your page, fetches the latest records, and renders them in a small, self-contained block. It is dependency-free and respects the host site's typography by using the system font stack.

1. Add the script

Paste this anywhere on the page where the widget should appear:

<script src="https://montanablotter.com/embed/blotter.js?county=Gallatin&limit=8"></script>

2. Configure

Param Default What it does
countyGallatinWhich county to show records for.
limit8Number of records. Max 25.
titleCounty BlotterCustom header text.
themelight"light" or "dark".
targetautoRender into this DOM id instead of injecting a new block.

3. What you can and can't do

  • Free for any non-commercial Montana civic, government, or local-news site.
  • Attribution link back to Montana Blotter must remain visible.
  • No PII is exposed — officer names, residential addresses, and personal phone numbers are stripped server-side.
  • For commercial or bulk use, see the B2B data API (coming soon).

Technical

The widget loads from /embed/blotter.js, fetches JSON from /api/embed/blotter.json, and renders inline. Both endpoints are CORS-enabled and cache for 5 minutes. No cookies, no tracking, no third-party scripts.
